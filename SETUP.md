# Publishing this navigation README

Local folder: `/Users/youming/Documents/Personal/Public/main.github`.

This folder is not yet a Git repository and has no remote configured.

## Organization profile

If `youminghu0930-public` is an organization, create or use the public repository `youminghu0930-public/.github`. Publish this folder there. GitHub displays `profile/README.md` on the organization overview. The root `README.md` also provides navigation when visitors open the repository.

## Personal profile

If `youminghu0930-public` is a personal account, the public profile repository must instead be named `youminghu0930-public/youminghu0930-public`. GitHub displays the root `README.md` on the profile. A `.github` repository does not activate a personal profile README.

The local folder name `main.github` can stay as it is in either case.

## Maintenance

The root and profile READMEs start with the same content. Keep both in sync when editing. All project navigation links point directly to published GitHub Pages URLs, using one repository-name path segment. The public repositories contain presentation frontends only; do not describe them as the underlying project source code. Publishing this README does not deploy those sites.
