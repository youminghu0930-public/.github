## Welcome

I'm Youming. This is a home for my public projects in computer vision and movement analysis. My current work uses golf swings to explore how RGB video can support reliable tracking, 3D reconstruction, and interpretable motion measurements.

Start with the **[portfolio](https://youminghu0930-public.github.io/)** for an overview, or explore a major project and its supporting work below. Each project page brings together the problem, approach, and interactive demonstrations. The public repositories contain presentation frontends only; the underlying implementation is confidential and is not published.

## How the projects connect

**Video → 2D detections → synchronized views → 3D motion → movement insights**

The 2D project focuses on reliable visual observations. True 3D builds on those observations to reconstruct and explain movement. The subprojects document the individual methods behind each stage.
